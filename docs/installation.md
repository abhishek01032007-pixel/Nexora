# Installation Guide

Nexora Skills Manager provides a streamlined Windows desktop installation experience.

---

## 📥 Standard Installation

### Step 1: Download the Installer
Download the latest Windows Installer (`NexoraSkillsManager-Setup.exe`) from the [Official Download Page](https://github.com/abhishek01032007-pixel/Nexora/releases/latest/download/NexoraSkillsManager-Setup.exe).

### Step 2: Run Setup Wizard
1. Double-click `NexoraSkillsManager-Setup.exe` to launch the guided setup wizard.
2. Select your desired installation options (Desktop shortcut, Start Menu shortcut).
3. Click **Install** to complete the setup.

### Step 3: Launch Nexora
- Open **Nexora Skills Manager** from the Start Menu or Desktop shortcut.
- Or run `nexora` from any terminal prompt (Command Prompt, PowerShell, Windows Terminal).

---

## ⚠️ Windows SmartScreen Notice

Initial releases are distributed without an enterprise Authenticode certificate. If Windows SmartScreen displays a warning:
1. Verify the download came from `https://github.com/abhishek01032007-pixel/Nexora`.
2. Click **More info**.
3. Click **Run anyway**.

---

## 🗑️ Uninstallation

To uninstall Nexora Skills Manager cleanly from your machine:
1. Open **Windows Settings** (`Win + I`) -> **Apps** -> **Installed apps**.
2. Search for **Nexora Skills Manager**.
3. Click the three dots menu (`...`) and select **Uninstall**.
4. Follow the uninstallation prompts.

> **Data Safety Guarantee**: Uninstallation removes only application binaries and shims. Your personal project files, workspace configurations, and custom skill definitions are strictly preserved.
