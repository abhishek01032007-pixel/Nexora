# Contributing to Nexora Skills Manager

Thank you for your interest in contributing to Nexora Skills Manager!

## Ways to Contribute

### 1. Community Skill Submissions (Public Repository)
We welcome developers to submit new AI agent skills to the official catalog.
- Skills must follow the standard SKILL.md format with valid YAML frontmatter.
- Fork this repository and add your skill under catalog/skills/<skill-name>/.
- Submit a Pull Request targeting the main branch.

### 2. Bug Reports & Feature Requests
- Check existing issues before opening a new one.
- Use our [Issue Templates](https://github.com/abhishek01032007-pixel/Nexora/issues/new/choose) to report bugs or request features.

### 3. Core Engine Collaboration (Private Repository)
Development of the core Windows desktop engine, Electron bridge, and PowerShell runtime is coordinated through our private development repository.
- To request collaborator access, submit an issue with the [Collaboration Request Template](https://github.com/abhishek01032007-pixel/Nexora/issues/new?template=collaboration_request.md) or reach out directly to maintainers.

## Code of Conduct
Please be respectful and constructive in all community interactions.
