# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

The Nexora project takes security and user privacy seriously.

If you discover a potential security vulnerability in Nexora Skills Manager, please follow these guidelines:

1. **Do NOT open a public issue** to report potential vulnerabilities or security flaws.
2. Please report the issue privately using GitHub's **Private Vulnerability Reporting** feature on the repository, or reach out to the project maintainers directly via repository mechanisms.
3. Include detailed steps to reproduce the issue, along with affected versions and environment details.

## Verification & Response

- Security reports will be acknowledged within 48 hours.
- Confirmed security vulnerabilities will receive patched releases with cryptographic SHA-256 validation.
